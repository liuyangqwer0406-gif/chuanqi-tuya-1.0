Lenis 只在输入/惯性期间申请帧；首屏离屏后暂停；液态按钮首次悬停或聚焦时才创建渲染器，离开后暂停；转场场景首次导航时才载入。

静态预览发现并修复 Next 16.3.2 的 Windows 导出路径问题：导出代码使用 `path.relative()` 的反斜杠，但生成预加载文件名时只替换正斜杠。
`postbuild` 将嵌套 `__next.*` 目录中的文本复制为浏览器需要的点分文件名，不修改依赖、不删除原产物；正常 Linux 导出无须额外复制。

## 复验命令

```sh
npm ci
npm run build
python -m http.server 4319 --bind 127.0.0.1 --directory out
```

另开终端执行（测试需要 Playwright 和 Microsoft Edge；`PLAYWRIGHT_PATH` 可指向已安装的 Playwright 包，否则使用本项目的 `playwright`）：

```sh
node scripts/audit-motion.mjs
node scripts/audit-export.mjs
```

两者都可通过 `AUDIT_ORIGIN=http://127.0.0.1:4319` 指定静态服务器。
两者默认地址都是 4319。
报告和截图写入 `output/qa`，属于忽略的本地验证产物。

Cloudflare Pages：仓库根目录构建，`npm run build`，发布 `out`；安装构建依赖时不要省略 devDependencies。
