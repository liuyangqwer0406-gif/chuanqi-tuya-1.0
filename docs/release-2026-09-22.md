# Portfolio motion v4 release

The approved v4 preview is integrated on top of remote main at
`defb47da7e44665af22444a4e86a6c08f25d460a`.

Includes the shared plant/particle hero, scroll narrative, responsive layout
refinements, case navigation and gallery interactions, visible liquid buttons
that remain lit, and pointer tracking across the hero iframe boundary.

Release checks also fixed root-relative font and fallback-image URLs so the
same assets load beneath the GitHub Pages repository base path. A pre-existing
unescaped JSX quotation in the format lab was escaped without changing its text.

Validation:

- Production build and TypeScript: 22 static pages.
- ESLint: zero errors; three warnings (loader lab hook dependency and two shader
  functions injected into the scene document at runtime).
- Interaction audit: desktop, 390px touch, gallery keyboard/focus, route changes,
  reduced motion, always-lit buttons and offscreen rendering suspension pass.
- Export audit: 22 HTML pages, 725 local references; home, about and seven cases
  load and decode 89 images with no failed resources or page errors.
- GitHub Pages base-path build and the same export audit pass.
- Cursor regression passes across the iframe, buttons, scrolling and keyboard
  interactions; touch devices keep the custom cursor disabled.

The old-work inventory and source archive reviewed separately are not part of
this release. Historical preview reports describe their state at that time.
